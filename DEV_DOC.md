# Developer Documentation

This project has been created as part of the 42 curriculum by elopez-u.

## Set up Environment from scratch

### Prerequisites

You must be running this project at a Linux SO, in my case I will be using Debian 13 Trixie. It is recommended to use Debian 11 version or forward. You can check your Linux version using `cat /etc/os-release`.

Clearly, you will also need to have Docker and docker compose installed. Run `docker --version` to see what version you use or whether you have it installed.

Every other dependencies will are specified in the Dockerfiles and will be installed during containers builds.

You will need to use `curl` command or just the browser of your choice to test if everything is working as expected.

### Configuration files

To be able to access WordPress via login.42.fr you will need to map that direction to 127.0.0.1 in /etc/hosts.

Each service has its own configuration file inside the conf folder. For example, nginx has its conf file at `/srcs/requirements/nginx/conf/nginx.conf`.

### Secrets

All credentials are stored in a `.env` file. In your `.env` file you will have to specify the credentials for MariaDB and WordPress services. It is very important not to upload this file to the repository, because it includes confidential information. The best practice to avoid this is to include `.env` extension to your `.gitignore` file.

## Build and Launch the Project

To set up the environment, clone this full repository into a Linux or macOS virtual machine and run `make up` from the project's root directory, where the Makefile is located. All my `make` commands call `docker compose`.

You can also run `make re` in case any error occurs during container generation, or in case you want to rebuild them.

Once the Docker containers are up, open [127.0.0.1](https://127.0.0.1), [localhost](https://localhost) or [elopez-u.42.fr](https://elopez-u.42.fr) in the web browser of your choice and you will access the WordPress sample page.

To access the WordPress Administration Panel, you just need to add /wp-admin to the previous mentioned URLs, for example, you can use [localhost/wp-admin](https://localhost/wp-admin).

## Relevant Commands

`docker exec -it <service-name> bash` lets you enter the container as if you were SSH-ing into it. For example:

```
docker exec -it srcs-mariadb-1 bash
mysql -u root -p

SHOW DATABASES;
USE wordpress;
SHOW TABLES;
```

## Project Data Location

You can list Docker volumes using `docker volume ls`. In this case, 2 volumes will be listed, as I did not explicitly define their names, they are autogenerated by Docker as srcs_mariadb_data and srcs_wordpress_data.

MariaDB data is stored in /home/elopez-u/data/volumes/srcs_mariadb_data/_data and WordPress data in /home/elopez-u/data/volumes/srcs_wordpress_data/_data as I specified in the docker-compose.yml file.
